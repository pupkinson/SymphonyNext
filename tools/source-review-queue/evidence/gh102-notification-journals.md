## Coverage and compatibility decision BEFORE patch

Existing Review is checked against candidate fields. Optional generation/HEAD fields are checked when present, never invented for ordinary Blocked results. A missing mandatory notice or partial directory is HOLD. No broad legacy skip and no file-presence admission.
